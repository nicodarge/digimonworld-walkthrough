Salut à toutes et tous.

Vous aimeriez jouer à Digimon World mais vous n’avez plus de CD ou de Playstation ?
Eh bah aucun soucis, vous allez pouvoir y jouer sur votre PC !
Comment ?

C’est ce que je vais vous expliquer tout de suite :
Pour faire cela nous allons utiliser un émulateur, un programme qui permet à partir de fichier ou de CD de jouer à des jeux sur son ordinateur (il en existe pleins, pour Gameboy, Playstation, Nintendo DS, GBA etc).

Ici nous utiliserons ePSXe

Normalement vous devriez aller sur le web, le télécharger ainsi qu’une multitude de plugins pour le faire fonctionner. Certain auraient du mal à s’en sortir je pense, s’est pourquoi je vais vous faire téléchargé mon ePSXe qui est DEJA configuré, vous n’aurez donc pas besoin d’aller aux 4 coins d’Internet pour voir après 1 heure que ça plante. Non, ici tout sera déjà là et prêt à être utilisé.

Le voici donc : http://kev8900.site.voila.fr/ePSXe.zip

Une fois téléchargé, ouvrez le dossier et aller sur le fichier nommé ePSXe.exe (si vous voyez les icônes, il peut ressembler à une manette de Playstation aussi).
Une petite fenêtre s’ouvre, voilà votre émulateur.

Mais attendez, nous allons le configurer pour qu’il puisse marcher !
Cliquez donc sur Config, ensuite Wizard Guide.
Cliquez sur Config, et sélectionner scph1001.
Clic sur Next, et puis sélectionner P.E.Op.S Soft Driver 1.17.
Clic sur Next, sélectionner Eternal SPU Plugin Lite 1.41.
Clic sur Next, sélectionner ePSXe WNT/W2K core 1.5.2.
Comme d’habitude Next, là vous arrivez aux contrôles. Vous pouvez les laisser comme ça ou les changer (c’est les touches qui correspondront aux contrôles de votre manette, penser à aller les voir ou les noter avant de jouer, façon de ne pas faire tout le clavier pour trouver à quel touche correspond X ).

Next, puis Done.
Voilou, nous avons terminé la configuration de l’émulateur enfin presque !
Etant donné qu’un ordinateur est bien plus puissant maintenant que votre Playstation, votre jeu risque de tourner assez rapidement…
Comment régler ce problème ?
Config => Video => Configure => Cocher la case « Use FPS Limit » => Cliquer sur OK
Cette fois ci, c’est bon !
