Emulation

Hey everyone.

Would you like to play Digimon World but you no longer have the CD or a PlayStation?
No problem at all — you can play it on your PC!
How?

That's exactly what I'm going to explain right now:
To do this we will use an emulator, a program that lets you play games on your computer from a file or a CD (there are plenty of them, for Game Boy, PlayStation, Nintendo DS, GBA, etc.).

Here we will use ePSXe

Normally you would have to go online, download it and then hunt down a whole bunch of plugins to make it work. Some of you might struggle with that, which is why I'm going to let you download my copy of ePSXe that is ALREADY configured — you won't need to spend an hour scouring the Internet only to end up with a crash. Everything will already be there and ready to use.

Here it is: http://kev8900.site.voila.fr/ePSXe.zip

Once downloaded, open the folder and go to the file named ePSXe.exe (if you have icons enabled, it may also look like a PlayStation controller).
A small window will open — that's your emulator.

But wait, we need to configure it first so it runs properly!
Click on Config, then Wizard Guide.
Click on Config, and select scph1001.
Click Next, then select P.E.Op.S Soft Driver 1.17.
Click Next, select Eternal SPU Plugin Lite 1.41.
Click Next, select ePSXe WNT/W2K core 1.5.2.
As usual click Next, and you will arrive at the controls screen. You can leave them as they are or change them (these are the keys that will correspond to your controller buttons — make sure to check or write them down before you start playing, so you don't have to mash the whole keyboard trying to figure out which key is X).

Next, then Done.
And there you go, we're almost done configuring the emulator!
Since a modern computer is much more powerful than your old PlayStation, the game may run quite fast…
How do you fix that?
Config => Video => Configure => Check the box "Use FPS Limit" => Click OK
This time, you're all set!

All that's missing now is the game (well, it's hard to play without one ^^).
You can find it here: http://www.megaupload.com/fr/?d=B64AQ92M
192.49 MB, so be a little patient.
Once the download is complete, extract the file.
Launch ePSXe (ePSXe.exe, which may again appear as a PlayStation controller icon).
Click on RUN ISO, browse to your Digimon World file, and off you go!

Note: I occasionally mention extraction. For .zip files there shouldn't be much difficulty, but .rar files can sometimes cause issues.
Use WinRAR for extracting those.
Available here: http://www.01net.com/tele[...]on/fiches/2257.html

The evaluation version works perfectly fine.

Have fun! ;- )
